# 자리났다 — 제품 요구사항 (PRD)

문서 기준일: 2026-09-23. 이 문서는 "무엇을, 누구를 위해, 왜"를 적는다. "어떻게"는 [SPEC.md](SPEC.md)에 있다.

## 1. 한 줄 정의

매진된 코레일 열차의 빈자리(취소표)를 사용자가 정한 조건대로 서버가 대신 지켜보다가, 자리가 나면 결제 전 예약까지 잡아 주고 알려 주는 Android 앱.

## 2. 대상 사용자와 상황

- 명절·주말·출퇴근 시간대의 KTX 매진 구간을 타야 하는 사람.
- 휴대폰으로, 급하게, 한 손으로 쓴다. 승강장·이동 중이 흔하다.
- 코레일 계정을 갖고 있고, 결제는 코레일에서 직접 한다.
- 앱을 켜 두지 않는다. "걸어 두고 잊는" 사용이 기본이다.

## 3. 사용자가 얻는 가치 (우선순위 순)

1. **놓치지 않는다** — 자리가 나는 순간 서버가 예약(홀드)까지 잡는다. 사람이 새로고침하지 않는다.
2. **원하는 자리만** — 열차·등급·호차·좌석(창가/복도, 앞뒤 줄 제외)까지 지정할 수 있다. 조건에 안 맞는 자리는 잡지 않는다.
3. **지금 상태를 안다** — 대기가 살아 있는지, 무엇을 기다리는지, 언제 마지막으로 확인했는지 홈에서 바로 보인다.
4. **되돌릴 수 있다** — 대기 중지, 예약 취소가 앱 안에서 두 번의 탭으로 된다. 결제만 코레일에서 한다.
5. **다시 걸기가 빠르다** — 자주 가는 구간은 한 번의 탭으로 열차 목록까지 간다.

## 4. 핵심 흐름 (해피 패스)

1. 홈에서 "새 여정 찾기" 또는 최근 구간/즐겨찾기 탭.
2. 출발·도착·날짜·시간대·인원·좌석 등급을 정하고 조회.
3. 열차 목록에서 (a) 카드를 눌러 좌석 무관으로 고르거나, (b) "기다릴 좌석 고르기"로 좌석표를 열어 조건(열·창가/복도·앞뒤 제외)과 호차를 골라 저장한다. 빈 좌석이 있는 열차는 "지금 예약할 좌석"으로 즉시 예약할 수 있다.
4. "조건 확인" 화면에서 요약을 보고 "지금 빈자리 찾기".
5. 홈 카드가 "찾는 중"이 된다. 앱을 닫아도 된다.
6. 자리가 잡히면 푸시 알림. 홈 카드가 "빈자리를 찾았어요"로 바뀌고 결제 기한과 코레일 결제 링크가 보인다.
7. 코레일에서 결제한다.

## 5. 기능 요구사항

### 5.1 홈
- 제목 아래에 "최근 구간 바로가기" 칩(최근 검색 1 + 즐겨찾기, 최대 3, 같은 구간·시간대는 하나)이 **대기 여부와 상관없이 같은 자리**에 있다. 칩이 없으면 이 줄은 없다.
- 상태 카드는 네 모습 중 하나다.
  - 대기 없음: 아이콘 + 흐린 "대기 중인 항목이 없어요". 배지·설명 없음.
  - 찾는 중: 배지 "찾는 중 · 1분 전"(마지막 확인의 상대 시각, 없으면 배지만) · 구간 · 날짜·시간대·인원 한 줄 · "자세히 보기 →" / "그만 찾기". 설명 문장은 넣지 않는다.
  - 문제(연결 끊김·조회 실패·확인 지연): 호박색 아이콘 + 제목 + 대처 문장 한 줄 + "자세히 보기".
  - 빈자리를 찾음(결제 대기): 예약 카드가 앞에 온다.
- "새 여정 찾기" 큰 버튼, 그 아래 "자주 가는 구간"(즐겨찾기 2개, 전체 보기).
- 칩·즐겨찾기 행을 누르면 **날짜만 묻는 시트**(오늘/내일 칩 + 날짜 입력; 시간대가 1시간 안에 끝나면 내일이 기본, "조건 수정" 링크로 폼 이동) → 바로 열차 목록. 인원·시간대·고른 열차 번호는 유지되고, 그 날 다니지 않는 열차는 빼고 알린다. 좌석표에서 찍은 자리는 유지하지 않는다.

### 5.2 열차 목록과 좌석
- 카드 탭 = 그 열차를 좌석 무관으로 선택(왼쪽 체크 표시 + 배지 "좌석 무관 선택", 안내 한 줄). 등급 버튼 = "일반실 · 기다릴 좌석 고르기"(매진) 또는 "일반실 · 지금 예약할 좌석"(빈자리 있음). "바로 예약"과 "코레일 예약 대기"는 확인 시트를 거친다.
- 좌석표: 열(A/B/C/D)·창가/복도 칩, "좌석 앞뒤 제외"·"호차 앞뒤 제외" 스테퍼(한 줄, 행을 가득, 값은 "0줄/0개"), 호차 탭(선택·지정·제외 표시), "모든 호차에 적용", 우상단 "선택 완료 · N석" 배지. 컨트롤은 48px. 대기 확인 버튼 "N석 중 빈자리 나면 예약"은 0석이면 비활성.
- 하단 버튼 하나: "다음: 조건 확인 →"(선택이 있으면 "N편 선택 · " 접두). 마지막 카드가 버튼에 가리지 않는다.
- 한 번의 자리 찾기 안에서 어떤 열차는 좌석 지정, 어떤 열차는 좌석 무관을 섞을 수 있다.

### 5.3 진행 중인 자리 찾기(자세히 보기)
- 상태 배지(정상 작동 / 확인 지연 / 조회 문제) + "N분 전 확인 · M회 조회" 한 줄(초 단위 없음). "상태 안내" 카드는 없고 시작 시각은 조건 표의 한 행.
- 조건 표: 출발, 열차(종류·편수), 편별 등급·호차·좌석(많으면 "N개 호차 · M석"), 좌석 등급·인원·배치, 좌석 지정.
- "그만 찾기"는 빨강 채움 버튼, 누르면 앱 안 확인 시트. 확인 화면 요약의 "좌석 지정" 행은 실제 저장된 좌석 계획을 근거로 쓴다.
- 조건 바꾸기(멈추고 새 조건으로 재시작, 결제 대기 열차는 잠금)는 다음 사이클.

### 5.4 예약(결제 대기)
- 결제 기한·좌석·예약번호·코레일 결제 링크. "예약 전체 취소"는 확인 시트를 거친다.
- 여러 명이 떨어져 앉아도 되면 한 자리씩 잡고 계속 찾는다("N/M석 확보").

### 5.5 즐겨찾기·알림·설정·계정
- 즐겨찾기: 이름·구간·시간대·인원·열차 종류·좌석 조건·열차 번호를 저장(날짜 없음). 행 탭 = 날짜 시트 → 목록, "조건 수정"으로 폼 편집, 삭제는 확인 시트를 거친다.
- 알림: 자리 확보·결제 기한 임박·조회 문제. 알림 간격 설정.
- 설정: 화면 테마(라이트/다크, 직접 고르지 않았으면 시스템을 실시간 추종), 앱 버전. 코레일 계정 연결/해제(해제는 확인 시트).

## 6. 상태 표시 원칙

- 조회 실패와 빈자리 없음을 구분한다. 확인되지 않은 자리 찾기를 정상으로 표시하지 않는다.
- 서버가 워커 생존과 마지막 확인 시각을 주고, 3분 넘게 확인이 없으면 "확인 지연", 연속 실패가 임계치를 넘으면 "조회 문제"로 보인다.
- 오프라인 배너는 상태 조회가 **연속 두 번** 실패(첫 실패 5초 뒤 재확인)하거나 OS가 오프라인이라 할 때만 뜬다.

## 7. 문구 원칙

- 해요체, 사용자 관점. "서버·등록·시스템" 같은 말은 쓰지 않는다.
- 백그라운드 대기는 "자리 찾기/찾는 중/그만 찾기", 코레일 열차 목록을 가져오는 것은 "조회", 코레일 공식 대기는 "코레일 예약 대기"로 구분한다. 화면 이름도 같다: 홈 "내 자리 찾기", 내 예약 "자리 찾기와 결제", 카드 링크 "자세히 보기".
- 같은 동작은 어디서나 같은 이름이다(멈춤 = "그만 찾기", 예약된 찾기 취소 = "예약 취소").
- 토스트는 상단에 뜬다(하단 주 버튼을 가리지 않는다).

## 8. 하지 않는 것

- 결제. 항상 코레일에서 사용자가 한다.
- 좌석표에서 찍은 자리를 즐겨찾기에 저장(2차 과제).
- 코레일 조회 한도(사용자당 60초 10회)를 넘기는 자동 조회.

## 9. 성공 기준

- 급한 첫 사용자가 도움 없이 4단계(조건 → 열차 → 확인 → 시작)를 마친다.
- 홈을 열면 1초 안에 "돌고 있나 / 뭘 기다리나 / 어떻게 멈추나"를 안다.
- 자리 확보 후 결제 기한 안에 결제 화면까지 두 번의 탭.

2. 알림을 제목·본문·결제 기한(남은 시간) 구조로(서버 템플릿 + 앱 표시). 지금은 서버 원문을 그대로 보여 준다.
